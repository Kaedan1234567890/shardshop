Chill Zone Shop / Shards 0.3.1-alpha-mc26.3-upgrades-opt-in

Changes from 0.3.0:
- Vein Miner permanent unlock now costs 1 Shard.
- Tree Chopper permanent unlock now costs 1 Shard.
- Both upgrades start OFF after purchase.
- Players may enable or disable either upgrade from its green/red toggle menu.
- Both upgrades can be owned at the same time.
- Existing 0.3.0 generated config values of 750/500 are automatically migrated to 1/1.
- Existing Deaths, Effect Bundles, Server Services, Shards, /baltop, and all other shop behavior remain unchanged.
