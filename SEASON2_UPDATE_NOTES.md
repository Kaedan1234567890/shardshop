# Chill Zone Shop 0.2.5 — uncompiled source
Restores an Upgrades slot at far right of the /shop GUI. Pickaxe = Vein Miner, Axe = Tree Chopper. Purchase each for 1 Shard, confirmation green wool or cancel red wool, automatically enabled and can toggle after purchase. Persists in config/chill-zone-shop-upgrades.json. Bounded 3x3 adjacent-log flood search with fast (staggered) visual leaf removal; bounded matching-ore vein search. IMPORTANT: source requires Minecraft integration testing and gameplay balance; verify other trees and build protections. Shop is an EXISTING separate mod; upgrades cannot be restored by changing Homes alone.
